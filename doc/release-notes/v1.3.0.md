# Resin v1.3.0

## Platform HTTPS Certificate Verification

- Custom Platforms can use normal system certificate verification, trust an
  imported CA certificate in addition to system roots, or explicitly skip
  certificate verification for exceptional upstreams.
- Import and manage reusable CA certificates from the WebUI or API. Resin
  validates and deduplicates imported certificates and prevents deletion while
  a Platform still references them.
- Platform settings and HTTPS certificate verification are saved together.
  The built-in `Default` Platform always keeps strict verification enabled.

## Upgrade Notes

> [!IMPORTANT]
> Persisted legacy Platform regex filters are automatically migrated to composable tag-filter rules during startup. This database migration is irreversible because earlier releases cannot represent OR or exclusion rules.

- Back up `<RESIN_STATE_DIR>/state.db` before upgrading.
- To downgrade to an earlier release, stop Resin and restore the pre-upgrade backup. Do not attempt to roll back the migrated database.
